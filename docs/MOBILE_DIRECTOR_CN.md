# 手机移动导演台使用说明

手机移动导演台是电脑端时间线导演台的配套网页界面。它通过同一个 ComfyUI 服务与对应的导演台节点配对，手机上的编辑会同步回该节点原有的 timeline_data，不会另建一套工作流数据。

## 1. 部署

1. 将本插件完整安装在 ComfyUI/custom_nodes/ComfyUI-MiniMaxH3-TimelineDirector 目录中。若你的实际插件文件夹名称不同，以实际名称为准。
2. 确认安装内容包含 mobile_sync.py、js/mobile_desktop.mjs，以及 js/mobile/ 目录中的 index.html、mobile.mjs、mobile.css、qrcode.mjs 和 THIRD_PARTY_NOTICES.txt。
3. 重启 ComfyUI，让 Python 后端路由和前端扩展重新加载。
4. 在工作流中添加或打开 MiniMax H3 时间线导演台节点。电脑端导演台标题栏中应出现“手机配对”按钮。

不需要额外安装 Python 包；本功能使用 ComfyUI 已有的 aiohttp 和浏览器原生 WebSocket。二维码生成代码随插件本地提供，不依赖第三方在线二维码服务。

## 2. 手机配对

1. 在电脑端打开需要控制的导演台节点，点击“手机配对”。
2. 电脑端会生成一次性配对码和二维码。
3. 手机与电脑处于同一可互通网络时，用手机相机扫描二维码并打开页面；如果无法扫描，也可以在手机浏览器中打开二维码显示的地址，再手动输入配对码。
4. 配对成功后，手机页面会加载对应节点的当前状态。之后在手机上修改分段、提示词、素材、分组、参考视频时间轴和设置，会同步回配对的电脑端节点。

配对码有时效且只能使用一次。重新配对会替换该节点之前的手机授权。

## 3. 家中局域网和外出访问

- 家中使用：手机连接能访问运行 ComfyUI 电脑的家庭网络，直接扫描电脑端生成的二维码即可。
- 外出使用：先在手机上连接你自己的 WireGuard VPN，确认 VPN 能访问家中运行 ComfyUI 的电脑，再打开电脑端重新生成的二维码地址或手动输入配对码。
- 地址和端口以电脑端二维码实际显示的内容为准。不要照抄示例 IP 或端口；ComfyUI Desktop、便携版和自定义启动方式可能使用不同端口。
- 如果二维码里的主机地址不是手机当前网络可达的地址，可在电脑端配对窗口中修改二维码地址后再扫描。修改的是访问地址，不会改变配对服务本身。

不建议把 ComfyUI 服务直接暴露到公网，也不需要为了本功能在路由器上配置公网端口转发。外出访问优先使用已配置好的 WireGuard VPN。

## 4. 连接状态和数据安全

- 手机和电脑端通过 ComfyUI 后端交换状态；WebSocket 负责实时通知，短暂断网后手机端会尝试自动重连。
- 如果断线期间两端都修改了内容，系统会暂停自动覆盖并提示冲突，避免静默丢失其中一端的修改。
- 手机端刷新页面后会尝试恢复当前浏览器会话。清除浏览器站点数据、使用无痕窗口或更换浏览器后，可能需要重新配对。
- 配对会话保存在 ComfyUI 进程内存中。重启 ComfyUI 后，旧会话失效，需要重新生成配对码。
- 电脑端删除对应导演台节点时，会撤销该节点的手机授权；手机端也可以在“连接设置”中主动断开。
- 配对二维码和配对码相当于临时访问凭据，请勿转发给不可信任的人。

## 5. 建议的首次测试顺序

1. 先确认电脑端原有导演台仍能正常编辑和生成。
2. 配对手机，确认手机能读取当前节点内容。
3. 在手机修改一段提示词，确认电脑端对应内容更新。
4. 在电脑端修改内容，确认手机端收到更新。
5. 测试素材分类移动、分组成员调整、参考视频拖动与裁切。
6. 暂时断开手机网络再恢复，确认连接自动恢复。
7. 在手机端主动断开，确认电脑端显示授权已撤销；再重新配对。
8. 删除一个测试导演台节点，确认该节点对应的手机连接被撤销。

首次测试请使用可丢弃的测试工作流副本，确认同步行为符合预期后再用于正式项目。

## 6. 当前限制

- 手机端是普通浏览器网页，不需要安装 App。
- 配对状态由当前 ComfyUI 进程管理；ComfyUI 重启后需要重新配对。
- 手机端页面必须能访问同一台 ComfyUI 服务的网页资源和后端 API。若网络隔离、防火墙或 VPN 路由阻止访问，配对将无法完成。
- 真实手机浏览器、不同 VPN 网络和具体 ComfyUI 安装方式仍需在目标环境中完成实际验收。
